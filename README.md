# 📸 照片／影片快速分類器（Streamlit）

本專案是一個使用 **Streamlit** 開發的本機照片與影片快速整理工具。
使用者可以逐一預覽資料夾中的圖片或影片，並透過按鈕將檔案快速分類到指定資料夾，以提升整理效率。

---

## ✨ 功能特色

* 支援圖片與影片即時預覽

  * 圖片格式：`jpg / jpeg / png / gif / bmp / webp`
  * 影片格式：`mp4 / mov / avi / mkv`
* 以按鈕方式一鍵分類檔案
* 支援跳過目前檔案
* 使用 Streamlit Session State 保留處理進度
* 全部處理完成後可重新掃描資料夾

---

## 🖥️ 環境需求

* Python 3.9 以上（建議）
* 本機可存取檔案系統（Windows / macOS / Linux）

---

## 📦 安裝與初始化（請務必先完成）

### 1️⃣ 建立虛擬環境（建議）

```bash
python -m venv venv
```

Windows：

```bash
venv\Scripts\activate
```

macOS / Linux：

```bash
source venv/bin/activate
```

---

### 2️⃣ 安裝套件（⚠️ 必須執行）

本專案使用 `requirements.txt` 管理相依套件，**請先安裝後再啟動程式**：

```bash
pip install -r requirements.txt
```

---

## 🚀 啟動方式

在專案根目錄執行：

```bash
streamlit run main.py
```

> 請將 `main.py` 替換為實際的程式檔名

瀏覽器將自動開啟：

```
http://localhost:8501
```

---

## ⚙️ 設定說明

### 📂 來源資料夾設定

請於程式碼中修改來源資料夾路徑：

```python
SOURCE_DIR = ""
```

系統會遞迴掃描此資料夾下的所有圖片與影片檔案。

---

### 🗂️ 分類目的地設定

可依需求調整分類按鈕名稱與對應的資料夾路徑：

```python
TARGET_CONFIG = {
    "家人": "./Sorted/Family",
    "工作": "./Sorted/Work",
    "風景": "./Sorted/Scenery",
    "垃圾桶/刪除": "./Sorted/Trash"
}
```

* 目的地資料夾不存在時會自動建立
* 檔案會使用 **move（搬移）** 而非複製

---

## 🔁 使用流程

1. 啟動程式後自動掃描來源資料夾
2. 左側預覽圖片或影片
3. 右側點擊分類按鈕將檔案移動至指定資料夾
4. 點擊「跳過此張」可略過不處理
5. 全部處理完成後可重新掃描

---

## ⚠️ 注意事項

* 若目的地資料夾已有同名檔案，可能導致搬移失敗
* 建議先使用測試資料夾進行驗證
* 「垃圾桶/刪除」目前僅為分類資料夾，**不會真正刪除檔案**
